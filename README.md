# RTG brief assets

Four small icons used by the CEO brief's Teams delivery (the age dial: a red dial that fills as a task ages past its due date). Public only so Teams can fetch them by URL; nothing here is confidential.

| File | Meaning |
| --- | --- |
| dial-1 | 1–7 days late |
| dial-2 | 8–14 days late |
| dial-3 | 15–30 days late |
| dial-4 | more than 30 days late |

PNG at 16, 32 (`@2x`) and 64 (`@4x`) pixels, plus SVG. Colour `#c00000`.
